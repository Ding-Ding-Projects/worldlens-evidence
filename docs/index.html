How to read the cards

Provenance is part of the image.

Every included file matches its source manifest hash. Five offline-guide images share source identifier 2e9162c87575a35fe6dd7c17282b39c1a26485aa. Nine native baseline images use source identifier 00290f2fb45f1b9bc9748b2db973d68aaa1a50c. The browser image uses source identifier fd74262d62d99990f999865543f105369b4875a0. These are provenance labels only. Neither the guide source nor the baseline revision is currently resolvable through the public Worldlens source repository; the baseline does not establish current-release behavior.

Capture timestamps are unavailable for all fifteen images. The build time shown inside one product screen is product UI content, not capture-time evidence. The nine new baseline captures separate native 1280 by 800 window images at 96 DPI from 800 by 600 renderer emulation. The latter is not native-window or display-scale proof. The configuration image is excluded because a shortcuts overlay obscures its content. The broader historical image set was not copied because its manifest records a local run and does not provide per-image privacy review for this gallery.
