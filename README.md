# [Worldlens visual evidence gallery](https://ding-ding-projects.github.io/worldlens-evidence/)

This public gallery presents six reviewed captures of Worldlens desktop companion surfaces. The images are genuine captures, copied without pixel edits from their reviewed source files. Their source manifests and this gallery's inventory record image hashes, source identifiers, capture route, visible state, and known limits.

Capture time is unavailable for all six images. The five native companion captures are bound to source identifier `2e9162c87575a35fe6dd7c17282b39c1a26485aa`; the personal-wording settings capture is bound to `fd74262d62d99990f999865543f105369b4875a0`. These identifiers are provenance labels only. The first source identifier is not currently resolvable through the public Worldlens repository, so this gallery does not claim public source availability or source verification.

The gallery deliberately excludes the broader historical `docs/screenshots/manifest.json` inventory. That inventory records a local run rather than a source revision and does not provide per-image privacy review for every listed capture. No image from that set was copied.

See [the complete capture inventory](docs/captures.json) and [the provenance notes](docs/features/captures/provenance.md). The companion app and its source are documented in the public [Worldlens Oak Kay](https://github.com/Ding-Ding-Projects/worldlens).
