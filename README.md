# [Worldlens visual evidence gallery](https://ding-ding-projects.github.io/worldlens-evidence/)

This public gallery presents fifteen reviewed captures of the Worldlens guide, build companion, and native baseline. The images are genuine captures, copied without pixel edits from their reviewed source files. Their source manifests and this gallery's inventory record image hashes, source identifiers, capture route, visible state, and known limits.

Capture time is unavailable for all fifteen images. The five offline-guide captures are bound to `2e9162c87575a35fe6dd7c17282b39c1a26485aa`; nine native Worldlens baseline captures are bound to `00290f2fb45f1b9bc9748b2db973d68aaa1a50c`; the personal-wording settings capture is bound to `fd74262d62d99990f999865543f105369b4875a0`. The new 1280 by 800 images are native captures at 96 DPI; the 800 by 600 images are renderer emulation, not native-window or display-scale evidence. These identifiers are provenance labels only. The guide and baseline revisions are not currently resolvable through the public Worldlens repository, so the gallery does not claim public source availability or source verification.

The gallery deliberately excludes the broader historical `docs/screenshots/manifest.json` inventory. That inventory records a local run rather than a source revision and does not provide per-image privacy review for every listed capture. No image from that set was copied.

The native baseline shows first-run setup, home, map, servers, and settings. The configuration frame is excluded because a shortcuts overlay obscures it. These images do not establish current-release behavior or completed features. See the [live evidence gallery](https://ding-ding-projects.github.io/worldlens-evidence/) for interactive filtering and image inspection, the [complete capture inventory](docs/captures.json), the [provenance notes](docs/features/captures/provenance.md), and the [sanitized baseline build record](docs/manifests/native-baseline-00290f2.json). The companion app and its source are documented in the public [Worldlens project](https://github.com/Ding-Ding-Projects/worldlens).
